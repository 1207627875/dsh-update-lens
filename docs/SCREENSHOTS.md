# 截图清单（给自己的操作单）

AI 截不了浏览器里的界面，这一步只能你自己做。按下面做，5 分钟能搞定。

## 怎么截

- **只截一块**：`Win + Shift + S` → 拖框选中 → 进剪贴板 → 粘到「画图」另存为 PNG。
- **截当前窗口**：`Alt + PrtScn`；**截全屏**：`Win + PrtScn`（自动存到 `图片\屏幕截图`）。
- 保存到本目录：`docs/`
- 文件名**必须**和下面一致，README 里按这些名字引用。

## 要截哪几张

### 1. `screenshot-1-overview.png` —— 整页（必备，门面）
- 打开 **设置 → 更新中心**。
- 窗口拉宽一点，让「当前版本 / 最新版本 / npm dist-tags」三个卡片排在一行。
- 从标题「DSH 更新中心」一直截到「手动更新命令」那一块。

### 2. `screenshot-2-breaking.png` —— 破坏性标注特写（必备，这是差异化）
- 往下滚到「更新内容」，点开「▸ 当前版本说明」，展开它。
- 截那一块：要能看到 **色条 + 「破坏性」「注意」徽章 + 「N 条破坏性变更 / M 条需留意」汇总**。
- 想把「命中词」也截进去：鼠标**悬停在某条标红条目上**，等 tooltip 出现再截。

### 3. `screenshot-3-toast.png` —— 右下角更新通知（可选）
- 这个提醒**只有真的存在更新版本时才出现**；如果你当前已是最新版，就截不到。
- 等真有新版本了再补这一张即可，README 里已说明。

### 4. `screenshot-4-settings.png` —— 设置与网络来源（可选）
- 同一页往下滚到「设置」「网络来源」，截「出口策略 + 每条来源的直连/代理标识 + 耗时」。

## 截之前注意

1. 「运行环境」卡片会显示 `DSH_HOME` 路径与 Node 版本。这不算密钥，但若不想公开机器路径，
   截图时把最底部那一块裁掉。
2. 这个页面只显示版本号与公开的 Release 文本，**不含任何密钥**；仍请扫一眼画面，
   确认没有别的窗口（终端、聊天、其它插件面板）露进来。

## 截完怎么入库

把 PNG 放进 `docs/`，然后在仓库目录执行：

```powershell
git add docs
git commit -m "docs: add screenshots"
git push
```
